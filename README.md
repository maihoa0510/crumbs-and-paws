# Crumbs & Paws

A cozy idle bakery game — bake treats, serve animal guests, grow your shop. Plain HTML/CSS/JS, no build step.

## Run locally

Double-click `start.command`, or:

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

Then open http://localhost:5173. Purchases and ads in the game are simulated.
